Политика конфиденциальности

Как FocusMate работает с вашими данными и почему ваши личные записи остаются на вашем устройстве.

Без аккаунтаБез рекламыЛокальное хранение
Дата редакции: 21 октября 2026 года · Приложение для Android

1. Общие положения

Настоящая Политика определяет порядок обработки информации при использовании мобильного приложения FocusMate (далее — «Приложение»). Разработчик: Chagin Konstantin (физическое лицо). Контакт для вопросов, связанных с конфиденциальностью: k.chagin@internet.ru.

FocusMate предназначен для организации повседневных дел, заметок и фокус-сессий. Приложение не выполняет медицинскую диагностику и не оказывает медицинских услуг.

2. Какие данные используются и зачем

По вашему желанию в Приложении могут сохраняться имя для обращения, названия и описания задач, небольшие шаги, заметки и идеи, списки ритуалов, сведения о местах хранения вещей, даты напоминаний и пользовательские настройки.

Данные используются для отображения задач, отслеживания их выполнения, формирования чеклистов, напоминаний, просмотра записей и восстановления сохранённой пользователем резервной копии. Содержание заметок определяется самим пользователем и может включать личную информацию.

FocusMate не требует создания учётной записи и не запрашивает пароль, номер телефона или адрес электронной почты для входа.

3. Локальное хранение и отсутствие серверной синхронизации

Основные пользовательские данные хранятся локально в памяти телефона. Приложение не использует собственный сервер для хранения пользовательских записей, автоматическую синхронизацию, встроенные рекламные сети, стороннюю аналитику или API нейросетей.

Разработчик автоматически не получает содержание ваших задач, заметок и чеклистов. В Android-версии отключено автоматическое облачное резервное копирование данных Приложения.

4. Микрофон и голосовой ввод

При добровольном использовании функции голосового ввода FocusMate запрашивает разрешение на микрофон и обращается к системной службе распознавания речи Android с запросом распознавания на устройстве.

Доступность офлайн-распознавания зависит от телефона, установленной речевой службы и языковых пакетов. Обработка данных системными службами устройства может регулироваться их отдельными политиками конфиденциальности. FocusMate не отправляет аудиозаписи на собственный сервер.

Если вы не разрешаете доступ к микрофону или офлайн-распознавание недоступно, можно вводить текст вручную.

5. Резервные копии

По вашей команде Приложение может подготовить резервную копию записей в формате JSON и скопировать её в буфер обмена. Пользователь сам решает, где сохранить такую копию или кому её передать.

Резервная копия не шифруется. Рекомендуется не отправлять её посторонним и хранить в защищённом месте. Данные из копии не поступают разработчику автоматически.

6. Сроки хранения, исправление и удаление

Данные сохраняются на устройстве до их удаления самим пользователем, замены при ручном восстановлении резервной копии или очистки данных Приложения средствами Android.

Записи можно изменять и удалять через интерфейс FocusMate. Чтобы полностью удалить локальные данные, используйте настройки Android → Приложения → FocusMate → Хранилище → Очистить данные. При удалении Приложения данные тоже могут быть безвозвратно утрачены.

Ранее экспортированные копии JSON необходимо удалять отдельно из тех мест, куда их сохранил пользователь.

7. Передача третьим лицам и сторонние компоненты

FocusMate не содержит встроенной отправки пользовательских записей разработчику и не продаёт пользовательские данные. Доступ к информации могут получать отдельные системные компоненты устройства при действиях пользователя: экранная клавиатура, службы доступности, голосовое распознавание или буфер обмена. Работа этих компонентов регулируется условиями их поставщиков.

8. Размещение данной страницы

Эта общедоступная веб-страница размещена через GitHub Pages. Разработчик не добавляет на неё собственные рекламные, аналитические скрипты или формы ввода данных. При посещении страницы сам сервис GitHub может обрабатывать техническую информацию о посещении по своей политике конфиденциальности.

Ваши записи из приложения не публикуются на GitHub Pages. Здесь размещён только текст политики конфиденциальности.

9. Изменение политики и контакты

При изменении функциональности Приложения текст политики может обновляться. Актуальная редакция публикуется по этому же адресу, с обновлением даты редакции.
